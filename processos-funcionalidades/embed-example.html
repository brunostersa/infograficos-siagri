📊 Embed: Processos & Funcionalidades Siagri

Guia prático para inserir o componente em seu site via iframe

O que é este embed?

O componente Processos & Funcionalidades permite que visitantes de seu site explorem os processos e funcionalidades de cada solução Siagri (Agribusiness, Agrimanager, Essencial, Web) de forma interativa.

Você pode embutir este componente em qualquer página usando um iframe e customizá-lo com parâmetros de URL.

📋 Gerar seu Código

Escolha a solução e a configuração desejada:

Copie o código abaixo:

<iframe src="https://brunostersa.github.io/infograficos-siagri/processos-funcionalidades/?sol=agribusiness" width="100%" height="100vh" style="border:none; display:block;"> </iframe>

💡 Clique no código para copiar

⚙️ Parâmetros de URL

Parâmetro Valores Descrição Exemplo
sol agribusiness
agrimanager
essencial
web		 Define qual solução é exibida por padrão ?sol=essencial
nav 0 Esconde a navegação/seletor (útil para embeds) ?nav=0

📱 Responsividade

O embed é totalmente responsivo. Use width="100%" para ocupar toda a largura do container pai.

Para otimizar a altura em dispositivos móveis, você pode usar JavaScript:

// Ajustar altura do iframe em mobile const iframe = document.getElementById('embed-iframe'); if (window.innerWidth < 768) { iframe.height = '800'; } else { iframe.height = '600'; }
